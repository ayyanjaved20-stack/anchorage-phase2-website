# Naval Anchorage Phase 2 – Real Estate Website

A production-ready real estate website developed for Naval Anchorage Phase 2 using WordPress, Elementor, and custom front-end development.

🌐 Live Website: https://anchoragephase2.com/

## Overview

This project involved designing and developing a responsive real estate website with a focus on performance, clean UI, and modern user experience. While Elementor was used as the page builder, a significant portion of the interface was customized using HTML, CSS, and JavaScript to achieve layouts and interactions beyond Elementor's default capabilities.

## Features

- Responsive design for desktop, tablet, and mobile
- Custom Elementor layouts
- Extensive custom CSS styling
- Custom HTML widgets
- JavaScript-powered interactions
- Third-party API integration
- Contact forms
- Interactive booking section
- Modern real estate UI
- Performance optimization

## Technologies Used

- WordPress
- Elementor Pro
- HTML5
- CSS3
- JavaScript
- REST APIs
- EmailJS
- LiteSpeed Cache
