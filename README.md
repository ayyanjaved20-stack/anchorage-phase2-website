## Overview

This project involved designing and developing a responsive real estate website with a focus on **modern UI, responsive design, custom interactions, and performance**.

While Elementor was used as the primary page builder, a significant portion of the interface was customized using **HTML, CSS, and JavaScript** to create layouts, components, animations, and interactions beyond Elementor's default capabilities.
